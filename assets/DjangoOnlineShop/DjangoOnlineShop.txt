فروشگاه آنلاین با جنگو و احراز هویت OTP (ناتمام)

یک پروژه فروشگاه اینترنتی که با معماری MVT جنگو توسعه داده شده است. این پروژه شامل احراز هویت با شماره تلفن و رمز یکبار مصرف (OTP)، مدل‌های دسته‌بندی بازگشتی (MPTT)، و تولید خودکار CRUD برای پنل کاربر و مدیریت است. برخی از بخش‌ها مانند سیستم اعلان‌ها، وبلاگ، سبد خرید و سفارشات هنوز تکمیل نشده‌اند.

DjangoOnlineShop (Incomplete)

An e-commerce project built with Django MVT architecture, featuring phone number and OTP-based authentication, recursive MPTT category models, and a dynamic CRUD view generator for both user and admin panels. Incomplete features include alerts, blogs, shopping cart, orders, and discounts.

Tech Stack:

Python (Django Framework)
AJAX
MPTT (Recursive Category Model)
Context Processors
Generic Relationships
OTP Authentication
