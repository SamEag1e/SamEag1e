افزودن اعضای گروه تلگرام با استفاده از Telethon

این ربات تلگرام با استفاده از کتابخانه Telethon، امکان ایجاد سشن و افزودن اعضای یک گروه تلگرام به گروه دیگر را فراهم می‌کند.

TgBotAddMember

A Telegram bot that utilizes the Telethon library to create a session and add members from one Telegram group to another.

Tech Stack:

Python
Telethon Library
Telegram API
