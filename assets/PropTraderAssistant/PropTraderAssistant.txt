دستیار تریدر برای محاسبه قوانین ۸۰٪ و اسکالپ در متاتریدر ۵

این ابزار ساده، با دریافت فایل HTML تاریخچه معاملات از متاتریدر ۵، قوانین ۸۰٪ و اسکالپ را برای ترید در حساب‌های پراپ فرم محاسبه می‌کند.

PropTraderAssistant

A simple tool that parses the trade history HTML file from MetaTrader 5 and calculates the 80% rule and scalp rule for prop firm trading.

Tech Stack:

Python
HTML Parsing (BeautifulSoup)
MetaTrader 5 Data Handling
