Python Mini Projects (MVC, ORM, OOP)
These relatively small Python projects include:

- Three terminal-based projects (online shop, reservation system, and educational management system) 
 using the MVC design pattern to better understand MVC, ORM, and OOP concepts.
- A mouse and keyboard logger project to work with multi-threading.
- A project comparing request execution times using different methods: multi-threading, multi- 
 processing, and asyncio.
- Several simple and intermediate regex tasks.
- Working with CSV, XLSX, directories, and files.
